# 多平台广告投放数据看板

把抖音 / 小红书 / 百度 / B站 四个投放平台的消耗、点击、转化数据统一口径汇总的复盘看板，解决多平台后台数据割裂、复盘靠手工拼表的问题。

## 功能

- 核心指标：广告消耗、曝光、点击、CTR、转化数、整体 ROI（含环比）
- 每日消耗 / 转化金额双曲线趋势图
- 分平台 ROI 对比、分客户投放明细表
- 异常规则引擎：CTR 低于平台均值 30% 预警、ROI<1 亏损提醒
- 客户 / 平台 / 周期筛选，一键导出 CSV

## 使用

双击 `index.html`，无需联网、无第三方依赖（原生 HTML/CSS/JS + SVG 手绘图表）。

## 数据说明

当前为**脱敏演示数据**（确定性伪随机生成，字段结构按真实投放后台设计）。真实使用时把各平台导出的报表按「日期/客户/平台/消耗/曝光/点击/转化」字段整理成数组替换生成器即可，分析逻辑无需改动。

## 面试可讲

- 多平台数据口径统一（去重、指标定义一致）是复盘可信的前提
- 复盘动作落地为规则引擎：CTR 异常 → 换素材/定向；ROI<1 → 收缩预算
- 指标链路：消耗 → CPC → CTR → CVR → ROI，能讲清每个指标影响什么决策
- 客户 ROI 排行把 ROI<1.5 标"待优化"：排行不是给老板看的，是给自己排优先级的
- 预算 pacing（已消耗/月预算，红>90%/黄70-90%）：预算将尽=加投机会，广告销售最有理由打电话的时刻；月预算口径=当月消耗/0.72（按目标节奏 72% 反推）
